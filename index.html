สูตรการคำนวณ RAM 3 ทาง และเกณฑ์ควบคุม

1. การคำนวณ Availability เมื่อทราบ MTBF และ MTTR:

A = (MTBF / (MTBF + MTTR)) × 100%

2. การคำนวณ MTBF เมื่อทราบ Availability (A) และ MTTR:

MTBF = MTTR × (A / (100 - A))

3. การคำนวณ MTTR สูงสุดที่ยอมรับได้ตาม Availability (A):

MTTR = MTBF × ((100 - A) / A)

4. เกณฑ์ควบคุม Availability (Target Threshold):

• ต้องไม่ต่ำกว่า 96.0% (Availability ≥ 96.0%) หากต่ำกว่าจะขึ้นสถานะเตือนสีแดงทันที
