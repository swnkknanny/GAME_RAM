สูตรการคำนวณ RAM และ Health Index

1. ความเชื่อถือได้ (Reliability - MTBF & Failure Rate):

MTBF = T_operating / Failures (N)

λ (Failure Rate) = Failures (N) / T_operating

2. ความสามารถในการบำรุงรักษา (Maintainability - MTTR):

MTTR = Total Corrective Downtime / Failures (N)

3. ความพร้อมใช้งาน (Operational Availability - A):

A = (T_operating / (T_operating + Total Downtime)) × 100%

4. การคำนวณ Health Index (HI %):

คะแนนเริ่มต้น 100% หักลบด้วยค่าถ่วงน้ำหนักความรุนแรงของแต่ละพารามิเตอร์ (Warning: -2.5% ถึง -5%, Critical: -10% ถึง -25%) ตามมาตรฐาน CIGRE และ IEEE
